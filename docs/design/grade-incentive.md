# 年级梯度激励策略 · 补充 `DESIGN.md` §2

> 本文件补充 `DESIGN.md` §2「分龄视觉规范」，把"年级"定义为**两档皮肤的切换开关**，并明确首批上线的"中高年级克制密度"皮肤与全曲线语调。
> 与 PM 决策一致：年级存 profile（localStorage），**不进 URL**；视频 P2 仅为外链卡、不参与任何激励（PM 规则 3）。
> token 命名对齐 `design-tokens.json`；图标名对齐 `docs/design/icon-spec.md`。

## 0. 一句话结论
统一激励引擎（徽章 / 积分 / 吉祥物星宝 / 庆祝动效 / 收藏册），**表达随年级从「童趣」平滑过渡到「成就」**；**不另建高年级系统**。三、四年级是铰链档，也是 P2 首批上线验证场。

## 1. 年级 = 皮肤开关（UX 落点）
- 切换入口**仅两处**：学习中心内（如"三年级 ▾"）、家长空间。**不放全局顶栏**——顶栏是低年级误触最高频区，六岁孩子误点"六年级"撞上超纲内容，挫败不可逆。
- 首次进入：**非阻塞**软引导卡（1–6 年级 + "先随便看看"跳过）；跳过按一年级呈现，但页面内留**常驻"设置年级"入口**（非反复弹窗）。
- 原则：可发现性给家长、误触率压给孩子。年级即 DESIGN.md §2 三档视觉密度的切换变量。

## 3. 首批皮肤：中高年级克制密度（三年级 / 四年级）
P2 交付顺序为 **3–4 → 1–2 → 5–6**，故这是首批上线验证场；**若只能先出一档，优先出这档**（与 PM 优先级一致）。

- **密度** `VISUAL_DENSITY ≈ 4–5`（相对全局基线 4 的轻微上浮——3-4 档比默认略密，仍属日常应用模式，非美术馆也非驾驶舱，勿与基线 4 视为两套冲突规范）；信息分组用 `divide-y` / `--c-line`，而非卡片盒子堆叠。
- **圆角**：卡片 `--r-md` 18px，按钮 `--r-pill` 或 `--r-sm`；避免 28px 过度圆滑。
- **强调色**：蓝 `--c-primary` 单色为主，每屏 ≤2 处；学科色 `--c-chinese` / `--c-math` / `--c-english` 仅作学科标签，不用于大块填充（避紫粉渐变）。
- **吉祥物**：星宝作"鼓励伙伴"，出现频率低于低龄档；表情用语义化 `mood-calm` / `mood-happy` / `mood-sad` / `mood-wow` / `mood-think`（见 icon-spec.md），不喧宾夺主。
- **庆祝**：真实完成（练习 / 打卡 / 徽章解锁）触发 `confetti` / `medal` / `rocket` 一次性庆祝，时长 ≤1.2s，全量 `prefers-reduced-motion`；**不可每题撒花**（避免噪音）。
- **成就框架**：徽章 `medal`、升级 `rocket`、加油 `muscle`；文案称"成就 / 里程碑"，避免"宝宝 / 宝贝"类幼龄词。
- **家长空间联动**：同档家长空间用 `--parent-calm` 中性收敛（DESIGN.md §6），去圆体降饱和。

## 4. 视频不参与激励（PM 规则 3）
P2 视频仅为脚本卡 + 官方微课外链，**不计分、不计时长、不进掌握度 / 打卡连续天数 / 家长周报成就项**；卡片不出现"已完成 / 已掌握"勾选或进度环，最多"上次看到这里"定位标记。本文件激励映射**只作用于真实完成**（练习、打卡、徽章解锁），以此护住"诊断可信度"核心资产。

## 5. 曲线连续性（待 PM 确认）
建议：1–2 童趣极 → 3–4 过渡（首批）→ **5 仍过渡、6 才完全成就极**，使语调连续无断崖。3–4 怎么定，整条曲线就定了。
