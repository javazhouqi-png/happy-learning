## 一、问题陈述

### 表面需求 vs 真实问题

主理人转达的目标是"内容深度扩充"。但我对 `src/data/content.js` 做了逐项盘点后，发现**真实问题不是内容少，而是最好的内容被隔离在学习闭环之外**。

实测内容盘点（非估算，逐项统计）：

| 内容资产 | 数量 | 是否进入学习闭环（错题本/掌握度/积分/打卡/周报） |
|----------|------|--------------------------------------------------|
| `LESSONS` 课时 | 9 节（语/数/英 各 3） | 进入 |
| `QUIZZES` 题目 | 36 道（**全部单选**，24 道带 grade 溯源、12 道无） | 进入 |
| `LESSONS[].texts` 统编篇目 | 16 篇（带教材出处 `ref`） | 部分进入 |
| `LESSONS[].texts[].exercises` 练习 | 43 道（**已支持 read/recite/think/fill/connect 五种题型**） | 部分进入 |
| `GRADE_LEARNING` 知识点 | 69 个（语 18 / 数 21 / 英 18 / 科 12，覆盖 1–6 年级） | **完全不进入** |
| `GRADE_LEARNING[].exercises` 练习 | **138 道** | **完全不进入** |
| `GRADE_LEARNING[].misconceptions` 易错点 | **138 条** | **完全不进入** |
| `VIDEOS` 视频 | 6 条 | 无媒体源，`setInterval` 模拟播放 |
| `docs/curriculum-roadmap.md` 知识图谱 | 约 70 个知识点（含学习意义 + 真实场景） | 仅文档，未进代码 |

三个结论：

1. **内容量的真实结构是"倒挂"的。** 参与激励闭环的题目只有 36 道（全单选）；而质量最高、最贴课标、带易错点辨析的 138 道题，躺在 `GradeLearning.jsx` 里——该组件源码注释明确写着"全部为只读展示，不写任何状态"。孩子在那里做完题，不入错题本、不计掌握度、不给积分、家长周报里看不到。**这不是内容单薄，是好内容没接上电。**

2. **主学习流没有年级维度。** `SubjectPage.jsx` 只 `import { getSubject, getLessons, VIDEOS }`——一年级和六年级的孩子打开语文页，看到的是同一批 9 节课、同一批 36 道题。而年级化内容（`GRADE_LEARNING`）在另一条独立入口里。两套内容体系并行且互不通气，是产品结构上最大的一处断裂。

3. **视频是假功能，且这是诚信红线而非功能缺口。** 6 条 `VIDEOS` 只有 `{id, subject, title, duration, desc}`，没有任何 `src`；播放进度由 `setInterval` 伪造。竞品调研里家长最集中的差评之一正是"课程与宣传不符、内容缩水"（洋葱学园黑猫投诉 429 条）。一个假播放条的杀伤力，远大于少 6 个视频。

### 现在怎么解决的 / 为什么不行

家长当前的替代方案是：国家中小学智慧教育平台（免费权威但是"资源仓库"，孩子不会自己每天打开）、付费 App（斑马/叫叫年费 1980–2800 元，且被自动续费与销售电话消耗信任）、纸质教辅 + 家长自己讲（家长根本不知道孩子哪里不会）。三条路都不解决同一件事：**家长看不见孩子的真实薄弱点，也不知道今晚该怎么陪。**

## 二、目标用户

### 主要用户 A：小学生（使用者）

- **年龄/学段**：6–12 岁，1–6 年级。内部差异极大，须分层看待：
  - 1–2 年级：**识字量不足，无法独立读题**——题干朗读与拼音标注是"能否自主使用"的生死线，不是加分项。注意力单次 5–8 分钟。驱动力来自即时反馈与收集养成。
  - 3–4 年级：可自主读题，开始出现学业分化（语文习作、数学"倍/分数"是分水岭）。注意力 10–15 分钟。
  - 5–6 年级：目标驱动出现（小初衔接），厌恶幼稚化视觉与"被安排"，需要"我自己选练什么"的掌控感。
- **场景**：晚饭后 15–30 分钟，家长的手机/平板或家庭电脑浏览器，常被打断。
- **技术水平**：无账号意识，不会记密码；能点击、能拖动，不擅长输入长文本。
- **痛点**：不知道今天该练什么（打开 App 面对一堆入口）；做错了没人告诉他为什么错；练了没有可见的"变强"证据。

### 主要用户 B：家长（决策者 + 陪学者）

- **画像**：28–45 岁，一二三线城市，本科为主，双职工。每晚可投入陪学 15–30 分钟。
- **政策处境**：双减后学科类校外培训受限（各地教育局寒暑假致家长信明确"任何形式学科类培训均属违规"），同时被要求"高质量亲子陪伴""亲子共读"。家长被推向"自己陪"，但没有工具。
- **消费心理**：预算收紧；对自动续费、退费难、销售电话高度警惕（这是跨中外儿童教育 App 一星差评的第一大类，且与"孩子有没有学到"无关）。
- **核心焦虑（真实需求）**：不是"孩子学了多久"，而是**"他哪里不会？我该怎么讲？"** 现有产品的家长端普遍只给时长与进度条，答不了这两个问题。
- **技术水平**：中等。要求"打开就能看懂，别让我先学怎么用"。

### 次要用户：教师 / 家委

需要可打印的周报或错题单，用于家长会与家访沟通。不需要账号体系，不需要班级管理（那是官方平台的地盘）。

| **纸质教辅 + 家长自己讲** | 零成本、家长最信任、无屏幕焦虑 | 无反馈闭环；家长批改后无法沉淀薄弱点；讲不动就放弃 |

### 差评的共性痛点（跨中外，六类）

对国内（洋葱学园）与海外（ABCmouse / Homer / Outschool / Duolingo ABC / Khan Academy Kids）一星至三星评价的交叉分析，痛点高度一致，且**大多与"教得好不好"无关**：

1. 取消订阅失败、试用期提前扣费、年费自动续费——最高频，甚至"how to cancel"本身成了搜索词
2. 退费难，以"超过 X 天不退"为由拒绝按比例退款
3. 低价引流 → 电话轰炸 → 高价长约；注销账号后仍被骚扰
4. 内容与孩子年龄/水平不匹配；新鲜感过后内容显得单薄、重复
5. **崩溃、进度丢失、更新后已获得的奖励消失**——对低龄儿童的耐心是致命打断
6. 面向儿童界面内的广告与升级弹窗——家长单独点名为"不合适"

## 四、我们的差异化

### 一句话价值主张

> **对齐课标的每日 15 分钟：孩子自己愿意练，家长一页看懂哪里不会、今晚怎么陪。不注册、不上传、无广告。**

### 三个市场空白（可占位置）

**空白一：课标同步 × 1–6 年级全覆盖 × 三科的轻量自学工具。**
识字类头部产品普遍卡在"学前至小学二年级"（洪恩 1300 字、悟空 1500 字），素养类（叫叫）不对齐课标，综合 AI 课（斑马）重心在低龄启蒙。3–6 年级"对着课标练、每天 15 分钟、不需要买课"这块地几乎空着。官方平台虽然全，但它是仓库不是工具。

**空白二：零账号、零上传的隐私可信度——把技术约束变成营销主张。**
在"退费难、电话轰炸、过度索权"是头号差评的市场里，"不注册、不上传、数据只在你自己的设备上、无广告、无内购、无销售电话"本身就是最锋利的卖点。我们纯前端 + localStorage 的既定约束，恰好正面命中这个空白，且竞品结构上无法跟进（它们的商业模式依赖账号与续费）。这一条必须写进首屏与家长空间，作为明示承诺。

**空白三：家长要的是"诊断"，不是"时长"。**
现有家长端普遍答"孩子今天学了 23 分钟、完成 3 节"。家长真正要的是"他哪里不会 + 我怎么讲"。我们已有错题本、间隔重复（SRS）、掌握度三块底座——把它们翻译成**"本周三个薄弱点 + 三条今晚 5 分钟怎么陪的具体动作"**，这个位置目前空着，且是我们最容易做到行业一流的地方。

## 五、内容扩充路线图

### 课标依据（《义务教育课程方案和课程标准（2022 年版）》，2022 年 4 月教育部印发）

**语文**：小学分三个学段，每学段按四个板块表述——识字与写字 / 阅读与鉴赏 / 表达与交流 / 梳理与探究。核心素养：文化自信、语言运用、思维能力、审美创造。

| 指标 | 第一学段(1–2) | 第二学段(3–4) | 第三学段(5–6) |
|------|---------------|---------------|---------------|
| 认字（累计） | 1600 左右 | 2500 左右 | 3000 左右 |
| 会写（累计） | 800 左右 | 1600 左右 | 2500 左右 |
| 背诵优秀诗文 | 50 篇(段) | 50 篇(段) | 60 篇(段) |
| 课外阅读总量 | 不少于 5 万字 | 不少于 40 万字 | 不少于 100 万字 |

**数学**：核心素养"三会"（会用数学的眼光观察、思维思考、语言表达现实世界）+ 四基 + 四能。学段目标：
- 第一学段(1–2)：万以内数、简单整数四则、立体与平面图形辨认、长方形正方形特征、长度单位、分类与数据意识、货币/时间/基本方向
- 第二学段(3–4)：自然数、小数与分数初步、较复杂整数四则、简单小数分数加减、运算律、常见平面图形周长面积、平移旋转轴对称、平均数、质量单位
- 第三学段(5–6)：用字母表示数、小数分数四则与运算一致性、面积体积表面积、有序数对、条形与折线统计图、百分数、可能性、负数

**英语**：分级体系——预备级（1–2 年级，仅有条件地区开设，以视听说启蒙为主，不要求书写语法）、一级（3–4 年级）、二级（5–6 年级）；**国家统一起始年级为三年级**。二级词汇表 505 词，各地可增加 100–300 词。核心素养：语言能力、文化意识、思维品质、学习能力。内容六要素：主题、语篇、语言知识、文化知识、语言技能、学习策略。三大主题范畴：人与自我、人与社会、人与自然。活动观：学习理解 → 应用实践 → 迁移创新。

> 注：项目 `docs/curriculum-roadmap.md` 已内置一份对齐上述课标的 1–6 年级知识图谱（约 70 个知识点，每点含"核心内容 / 学习意义 / 真实场景"），且已明确标注英语起始年级口径。**内容扩充应以该文档为唯一内容源，避免二次考据与口径漂移。**

### P0 阶段：接上电 + 补齐骨架（优先级最高，成本最低）

1. **把 `GRADE_LEARNING` 的 138 道题接入学习闭环。** 这是本轮性价比最高的一项：题库从 36 道立刻变成 174 道，新增内容成本为零。前置条件——这 138 道题目前**没有 id 字段**（`{q, options, answer, explanation}`），错题本以 `question.id` 记录，必须先补稳定 id（建议 `{pointId}-e{n}`，如 `g1-cn-pinyin-e1`）。已同步架构师。
2. **主学习流补年级维度。** 首次进入选年级（可在家长空间修改），全站内容按年级过滤；1–2 年级英语按"预备级/听说启蒙"呈现并保留口径说明。
3. **题型从 1 种扩到多型引擎（对齐架构师锁定的 `QuizType` 共 7 型）。** `LESSONS[].texts[].exercises` 已实现 read/recite/think/fill/connect 五型，是现成契约，无需重新设计。P0 主答题引擎按 `type` 调度渲染 7 型：单选、填空/选字、连线、排序（数序/句序/笔顺）、朗读、背诵、简答思辨（后三型为自评式，无自动判分，不伪造正确率）。**全部单选的题库对语文识字与数学计算是失真的**——识字要"选字填空"，计算要"填空"，笔顺要"排序"。
   > 注：PRD 初稿曾把"听力辨音"列为第 6 型。经与架构师对齐——纯前端无音频资产管线时，"听音辨义"本质是"题干由浏览器语音合成朗读的单选/填空"，属**呈现变体而非新数据型**，故不单列 `QuizType`，归并到 P1 语音支持（RICE #10，非 MVP）。
4. **题库补四个溯源字段**：`grade`（年级）、`point`（课标知识点 id）、`type`（题型）、`level`（识记/理解/应用/易错辨析）。当前仅 24/36 道有 `grade`。溯源字段是后续"按薄弱点重练""诊断报告"的数据前提，且四字段须一并写入错题记录的持久化结构（架构师已锁 `WrongEntry`），P1 做诊断报告时无需反查题库。另加 `unit` 字段（可暂空，见下方内容文件组织）。
5. **假视频立即降级（诚信红线，本阶段必做）。** 移除 `setInterval` 伪播放进度。6 条 `VIDEOS` 改为"知识点动画脚本卡"：分镜要点文字 + 配套练习 + 明示"动画制作中"。宁可少一个功能，不可留一个假功能。

P0 目标产出：知识点 69 → 108（语数英各年级 6 点，数学按现有 3–4 点补齐至 `curriculum-roadmap.md` 的 4–7 点）；题库 36 → 540（每知识点 5 题：1 识记 + 2 理解 + 1 应用 + 1 易错辨析）；题型 1 → 7（对齐架构师锁定 `QuizType`）。

### 内容文件组织（与架构师共同锁定）

按 **`g{年级}/{学科}.ts`** 组织，共 18 个内容文件（6 年级 × 3 学科），配 `manifest` 索引供错题反查题面。540 题落到 18 个文件约 30 题/文件，首屏不加载任何题库字节。

内容生产按这 18 个文件为最小交付单元，好处是**可分批验收、可分批上线**：一个年级一个学科写完即可合并，不必等 540 题全部就绪。建议交付顺序按用户密度——先三、四年级（学业分化拐点，家长焦虑最强），再一、二年级（需配套朗读与拼音，依赖 P1 语音能力），最后五、六年级（内容最难，但该年龄段自驱最强、容错更高）。

**给 P1 留的口子**：`单元诊断卷` 会需要单元维度分组。届时下沉为 `g{年级}/{学科}/{unit}.ts`，架构师已确认加载器同构扩展、不改架构。因此 P0 阶段**每道题仍须带 `unit` 字段（可暂为空）**，避免 P1 回填时反查教材目录。

### P1 阶段：深度与分层

1. 每知识点补足五段结构（`GRADE_LEARNING` 已有此 schema，直接扩量）：`analysis` 讲透 + `misconceptions` 易错 3 条 + `applications` 生活应用 2 条 + `spiral` 学段衔接 1 条。**`misconceptions` 是我们对比免费 AI 的护城河**——AI 能答题，但不会主动告诉家长"你孩子这类题错是因为把'的/得/地'混了"。
2. 语文补"必背古诗文"目录级索引，对齐小学三学段合计 160 篇(段)；正文只收公版内容，先做目录 + 朗读 + 背诵打卡。
3. 单元诊断卷：每年级每科每学期 1 套（20 题），出诊断报告（薄弱知识点排序 + 错因分类）。
4. 英语补语音：题干与单词朗读走浏览器语音合成；跟读比对降级为"自评 + 录音回放"（无后端约束下的诚实方案，不假装 AI 打分）。
5. 数学补错因分类：计算失误 / 概念不清 / 读题偏差——家长周报直接引用。

### P2 阶段：真实视频（按成本与风险排序，三条路线）

1. **首选：自绘图文动画课。** SVG/CSS 关键帧自制 2–3 分钟知识点动画，零版权、零带宽、零外部依赖，100% 自研可控，纯前端天然适配。知识点颗粒度对标洋葱学园动画微课（5–8 分钟）但更短，契合小学注意力。
2. **次选：官方名师微课外链。** 不内嵌、不转存，跳转国家中小学智慧教育平台对应课节。合法、免费、权威——**把最强替代方案变成我们的内容补给，而不是对手**。这一步同时强化"我们不卖课"的可信形象。
3. **末选：自制录屏讲解。** 成本最高、更新最难，仅用于高频难点。

**绝不做**：占位视频 + 假播放进度条。这是本项目已经踩过的坑。

### 两条诚实边界（对外措辞口径，与架构师共同确认）

纯前端无后端的既定约束下，有两项能力做不到"强"，因此**产品措辞必须与实现能力一致**——这与本项目已经处理过的假视频问题是同一条原则：宁可少承诺，不可虚标。

1. **家长验证是"示意"，不是密码学强验证。** 家长 PIN 存于 localStorage，通过 DevTools 可绕过。因此对外一律称"家长验证示意"或"家长确认"，**禁止使用"强管控""家长锁""无法绕过"等措辞**。它的产品定位是给孩子一道"这是家长的区域"的心理门槛与误触保护，不是防破解。同理，家长空间对外表述为"用眼与时长提醒"，不叫"家长控制"。
2. **视频"已查看"不给任何激励。** 视频区在 P2 前只有脚本卡与官方外链，无法验证是否真的看完。若需要"回到上次看的地方"，仅允许记一个无积分的 `viewedVideos` 集合，且**不计积分、不计学习时长、不进掌握度、不进打卡连续天数、不进家长周报成就项**。理由：一个点开就算"学过"的标记，本质上是假数据，会污染家长诊断报告的可信度——而诊断可信度是我们对比免费 AI 的核心资产。

## 八、验收标准（Given / When / Then）

**年级分层**

> 唯一真相源：年级存于 profile（localStorage），**不进 URL 路由参数**。理由见下方"年级选择与切换的产品裁决"。

- Given 首次打开应用且未选过年级，When 进入首页，Then 出现年级选择引导（1–6 年级 + "先随便看看"跳过项），且不阻塞浏览
- Given 选择了"先随便看看"，When 浏览学科页，Then 按一年级内容呈现，并在页面内保留一处"设置年级"的常驻入口，不反复弹窗打扰
- Given 已选三年级，When 进入语文学科页，Then 只呈现三年级知识点与题目，且页面标题明示"三年级 · 语文"
- Given 已选一年级，When 进入英语学科页，Then 呈现预备级听说启蒙内容，并展示"国家统一起始年级为三年级"的口径说明
- Given 已选年级，When 在学习中心的年级切换控件或家长空间修改年级，Then 已有错题与掌握度数据保留不清零，仅内容范围切换
- Given 页面刷新或重新打开浏览器，When 应用启动，Then 从 profile 恢复上次年级，不要求重新选择

### 年级选择与切换的产品裁决

**年级不进 URL。** 路由保持学科维度（`/learn/:subjectId`），年级由 profile 提供。原因：本产品是单用户、无账号、以"记住这个孩子"为前提的工具，不存在分享链接与多人协作场景；一旦年级同时存在于 URL 与 profile，就会出现"家长收藏了 `/learn/3/chinese`，后来把孩子改成四年级，收藏夹点开又回到三年级"的冲突。单一真相源换来的确定性，远大于深链带来的收益。刷新与后退行为不受影响（profile 从 localStorage 恢复）。

**切换入口放两处，都不放全局顶栏。** 学习中心内放一处明确的年级切换控件（如"三年级 ▾"），家长空间放一处。**不在全局顶栏常驻**——顶栏是低年级孩子最高频误触的区域，一个六岁孩子随手点到"六年级"，看到负数和圆柱体积，挫败感是直接的。切换本身不需要家长验证（那太重），但要放在需要一次明确意图的位置。

**打通 GRADE_LEARNING**
- Given 在年级知识点页做题，When 答错一道题，Then 该题进入错题本，且掌握度、积分、打卡与家长周报同步更新
- Given 同一道年级知识点题被答错两次，When 打开错题本，Then 该题只出现一条记录（按稳定 id 去重），并显示累计错次

**假视频治理**
- Given 打开视频库，When 点击任一条目，Then 呈现该知识点的动画脚本卡（分镜要点 + 配套练习），明示"动画制作中"，且**不出现任何自动推进的播放进度条**
- Given 条目配有官方微课外链，When 点击外链，Then 在新标签打开国家中小学智慧教育平台对应页面，并提示"即将离开快乐学园"

**学习档案导出/导入**
- Given 已有学习记录，When 点击导出，Then 下载一个含版本号的 JSON 档案文件
- Given 持有导出文件，When 在空白浏览器导入，Then 完整恢复错题、掌握度、积分、徽章、打卡记录
- Given 导入的文件版本号高于当前应用，When 执行导入，Then 拒绝导入并给出明确提示，不破坏现有数据

**每日学习任务单**
- Given 今日未学习，When 打开首页，Then 首屏呈现"今日三件事"，每件均可一键进入
- Given 今日三件事全部完成，When 回到首页，Then 呈现完成态与明日预告，不再重复派发同一批任务

**未成年人模式**
- Given 连续使用达 30 分钟，When 触发提醒，Then 弹出休息提示（含"起身远眺 20 秒"建议），可延后但不可永久关闭
- Given 当前时间在 22:00—6:00，When 打开应用，Then 呈现休息提示页，需家长验证示意方可继续
- Given 家长要修改每日建议时长，When 进入设置，Then 须先通过家长验证示意
- Given 家长验证示意的相关界面，When 呈现说明文案，Then 不出现"强管控""家长锁""无法绕过"等超出实现能力的措辞

**空状态引导**
- Given 从未答过题，When 打开错题本，Then 呈现空状态插画 + 一句解释 + "去做今日三件事"的直接入口——不出现空白页或加载骨架屏卡死

### 数据埋点方案（纯前端适配版）

本项目无后端且承诺零上传，因此埋点定位调整为：**写入 localStorage 的本地事件日志，服务于家长周报生成与开发期自查，永不出网**。

| 事件类别 | 事件名 | 用途 |
|----------|--------|------|
| 激活 | `grade_selected` | 是否完成年级选择（首次体验是否走通） |
| 激活 | `first_core_action` | 首次完成一道题——真正的激活点 |
| 核心 | `question_answered` | 附 `grade / subject / point / type / level / correct`，是诊断报告与掌握度的唯一数据源 |
| 核心 | `daily_task_completed` | 今日三件事完成情况，喂给打卡与周报 |
| 留存 | `session_start` / `session_duration` | 连续使用时长（同时驱动 30 分钟休息提醒） |
| 内容 | `video_script_viewed` / `external_lesson_opened` | 动画脚本卡与官方微课外链的实际使用度，决定 P2 视频投入方向 |
| 异常 | `storage_write_failed` / `import_rejected` | 定位"进度丢失"类问题——竞品第 5 大差评 |

约定：事件命名 `{对象}_{动作}`；每条附 `timestamp / appVersion / grade`；**不采集 IP、设备指纹、原始输入内容**；日志容量上限固定（建议 2000 条滚动淘汰），避免挤占 localStorage 配额。

## 十一、给主理人的一条需求反馈

主理人下发的表述是"内容深度扩充"。基于实测盘点，我建议把首要焦点微调为**"先接上电，再扩充"**：

用户真正要的不是"课程数从 9 变成 100"，而是"孩子明天还愿意打开、家长能看懂哪里不会"。当前 138 道最优质的题目在闭环外空转、主学习流没有年级维度、视频是假的——这三件事不修，新增的内容只会同样落在闭环外，扩得越多，产品的"展示型 demo"气质越重。

判断"行业一流"的指标建议定为：**次日打开率**与**家长能否在一屏内说出孩子的三个薄弱点**。这两个指标不靠内容数量，靠闭环完整度。
