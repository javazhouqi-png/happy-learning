# 题库规模分析 · 答题功能改进方案

> 关联需求：分析题库内容规模、评估各年级覆盖是否充足、提出答题功能改进方案，并修复「各年级学习进度显示完全相同」的缺陷。
> 数据来源：`src/data/content.js`（`QUIZZES` + `GRADE_LEARNING`）、`src/data/subjects.js`（`LESSONS`）。统计脚本运行时实测。

## 一、题库规模（实测）

答题库由两部分合并而成（`getQuiz(subjectId, grade)` = 共享基础题库 + 该年级分层练习）：

| 题库 | 规模 | 说明 |
| --- | --- | --- |
| 基础题库 `QUIZZES` | **36 题**（每科 12） | **跨 6 个年级完全共享**，无年级区分 |
| `GRADE_LEARNING` 分层练习 | 年级 1–3 各 18 题；年级 4–6 各 20 题 | 按年级独立，是真正“分年级”的内容 |
| **每一年级实际答题库** | **54–56 题**（语/数/英各约 18–20） | = 36 共享 + 18~20 当年练习 |
| 全 6 年级合计（题次） | **330 题次** | 含重复计入的 36 共享题 |
| 去重后独立题目 | 约 **150 题** | 36 基础 + 各年级练习累加 |

## 二、覆盖度评估

**结论：总量可观，但“分年级精准覆盖”不足，且存在结构性 duplication。**

1. **单年级单科仅 18–20 题，偏薄。** 对一次完整练习（~10 题）够用，但难以支撑「间隔重复 / 多轮变式训练」。尤其数学高年级只比低年级多 2 题，知识深度拉开后题量没有相应增加。
2. **36 道基础题库被 6 个年级共享，且内容与低年级对齐。** 例如拼音、识字类题目对 4–6 年级并不适配——高年级学生做题库里仍会反复出现一年级水平的题，既无挑战也浪费练习机会。**这是最大的覆盖质量问题。**
3. **英语起始年级为三年级（课标口径），但基础题库的英语题（字母/颜色/动物）属预备级。** 4–6 年级英语没有对应提升，明显断层。
4. **科学等学科未进入闭环。** `GRADE_LEARNING` 部分年级含 `science` 补充学科，但 `getQuiz` 仅覆盖语/数/英，科学练习“只读不练、不计掌握度、不入错题本”。
5. **知识点 ↔ 题目映射有限。** `GRADE_KNOWLEDGE` 知识点多于 `GRADE_LEARNING` 练习，部分知识点缺少对应练习。

## 三、答题功能改进方案（按优先级）

| 优先级 | 方案 | 预期收益 |
| --- | --- | --- |
| P0 | **基础题库按年级打标/拆分**：把 36 道 `QUIZZES` 归入对应年级（多为 1–2 年级），或改为可选“跨年级复习包”，不再默认塞给所有年级 | 消除高年级做一年级题的错位，提升覆盖精准度 |
| P0 | **单年级单科题量升至 30–40**：按知识点补齐变式题（同考点不同情境/数值） | 支撑多轮练习与间隔重复，避免“背题” |
| P1 | **错题 ↔ 教材/知识点闭环**：错题记录已带 `grade/subject/pointId/pointTitle`，可在错题本按知识点分组、一键跳回教材解析与对应练习 | 把“错在哪、为什么错、怎么巩固”形成闭环 |
| P1 | **互动学习模式**：闪卡（字词/单词）、口算闯关（计时）、听写/跟读打卡 | 提升低龄学生参与度，丰富“答题”形态 |
| P2 | **科学等学科接入闭环**：`getQuiz` 纳入 `science`，掌握度/错题本覆盖全学科 | 消除“只读不练”的内容债 |
| P2 | **自适应难度**：依据 `quizByGrade` 正确率，自动调配易/中/难题比例 | 让练习始终处于“最近发展区” |

## 四、本次已修复：各年级学习进度独立追踪与展示

**缺陷**：`GradeLearning`（年级分层学习）用 1–6 年级 Tab 切换，但进度展示直接读取**全局** `derived.mastery[学科]`，因此所有年级显示完全相同的掌握度——并未真正按年级区分。

**修复**：在状态层新增按年级维度，使每个年级独立累计、独立展示。

- `src/state/types.ts`：`AppState` 新增 `quizByGrade: Record<number, Record<SubjectId, SubjectStat>>`。
- `src/state/storage.ts`：默认态与 `migrate(v1→v2)` 补齐 `quizByGrade`（各年级默认空，旧档安全合并）。
- `src/state/reducers/progress.ts`：`ANSWER_QUIZ` 在记录全局 `quizBySubject` 的同时，按**当前年级 `state.grade`** 写入 `quizByGrade[grade][subject]`。
- `src/state/AppContext.jsx`：派生 `derived.progressByGrade[grade][subject] = { correct, total, mastery }`（掌握度 = 该年级自身正确率）。
- `src/components/modules/GradeLearning.jsx`：学科 Tab 与概览改用 `derived.progressByGrade[grade]`，并显示「已练 X/Y 题 · 掌握度 Z%」。

**效果**：切换年级 Tab 时，各年级答题进度、完成状态、掌握度均按各自数据区分显示；未学习年级显示 0%/空态，已学习年级显示真实进度，不再“千篇一律”。

**验证**：reducer 单测（esbuild 打包 + node 断言）14/14 通过（按年级独立累计、互不串台、迁移保留）；`vite build` 通过，主 chunk 44.16 kB < 184320 B，配色门禁通过。
